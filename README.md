# Enterprise Analytical Administration Portal

A modern and interactive **Enterprise Analytical Administration Portal** built as part of the **Progree Internship – Frontend Development Task 4**.

The application provides an enterprise-style dashboard for monitoring business performance, analyzing metrics, managing users and reports, and tracking system activities through interactive data visualizations.

---

## 📌 Project Overview

The **Enterprise Analytical Administration Portal** is a multi-view client-side business analytics application designed to present organizational data through a clean, structured, and interactive dashboard.

The project focuses on:

- Business analytics and KPI monitoring
- Interactive data visualization
- User and report management
- Client-side data searching and filtering
- Multi-column table sorting
- Dark/light theme management
- Cross-browser compatibility
- Responsive chart components

Mock JSON data is used to simulate real-world enterprise information such as users, departments, reports, KPIs, and system activities.

## 📊 Data Visualization

The project uses **Recharts** to create interactive analytical visualizations.

Charts are connected to mock JSON data and include responsive components such as:

- Line charts
- Bar charts
- Pie charts
- Area-based visualizations
- Department performance charts
- Activity statistics

The charts use `ResponsiveContainer` to adapt to their available container dimensions.

---

## 🔎 Client-Side Data Operations

The application implements client-side data manipulation without requiring a backend database.

### Searching

Users can search records using client-side search functionality.

### Filtering

Data can be filtered based on relevant categories such as:

- Department
- Status
- Report type
- Activity type
- Time period

### Multi-Column Sorting

Data tables support sorting across multiple columns to make enterprise records easier to analyze and compare.
